# Manuais fora do repositório público

Os PDFs dos manuais pertencem aos fabricantes e não são redistribuídos: ficam numa pasta local ignorada pelo git, assim como a base vetorial gerada a partir deles. O que é versionado é um registro de manuais (marca, códigos de modelo cobertos, link de origem, arquivo local esperado) que permite a qualquer pessoa baixar os mesmos arquivos e reconstruir a base com o comando de indexação.
